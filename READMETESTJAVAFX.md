## Ứng dụng Desktop (Quầy vé - FU Cinema)

### 1. Yêu cầu hệ thống
- **JDK:** 21
- **Công nghệ:** JavaFX 21.0.x, Spring Boot 4.1.1, SQL Server
- **Hệ điều hành:** Windows 11 / macOS / Linux hỗ trợ giao diện

### 2. Cách chạy ứng dụng
- **Chạy qua IntelliJ IDEA:** Chạy file `com.fu.cinema.desktop.DesktopLauncher`
- **Chạy qua Maven (Desktop):**
  ```bash
  mvn spring-boot:run -Dspring-boot.run.main-class=com.fu.cinema.desktop.DesktopLauncher
